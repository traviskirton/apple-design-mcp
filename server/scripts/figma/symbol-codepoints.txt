# The SF Symbols that Apple's UI kits use, by the private-use code point each has in the SF Pro font.
# One "HEX name" per line. scripts/build-ui-kit-pack.mjs prints the name in place of the code point.
#
# Apple publishes no table of code points, and the font's glyphs are named by code point. The names
# here were found on 2026-11-19 by shape: scripts/symbol-glyphs/match.swift compares each glyph in
# SF Pro 22.2d2e1 with the outline of every symbol, and resolve.mjs picks among identical shapes.
# Identical shapes: a pair such as chevron.left and chevron.backward differs only in right-to-left
# layouts, so the two names of a pair could be the other way round (10012B/100C11, 100189/100BF6,
# 100147/101086, 10019B/101088, 10013C/100C4D, and 100C53). 100061 could be xmark.circle.fill.
# Checked by eye because the font draws them a little differently: 100264, 10020F, 100263, 1001D5,
# 10020E, 100647.
