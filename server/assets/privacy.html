Privacy

What the server keeps.

No account, no cookies and no record of your conversations. Updated 20 November 2026.

No account

The server needs no sign-in, key or account. It sets no cookies, and this site runs no analytics or tracking scripts.

What an app sends

An app such as Claude calls the server's tools with short inputs: a device name, the components and icons a design needs, or a guidelines topic. The server answers from Apple's published material and keeps no copy of your conversation, your prompt or your design. It never sees them; the app sends only the tool inputs.

What is logged

To keep the server running and see which tools are used, each tool call is logged with the tool's name, its inputs, the size of the reply, whether it failed, and the app name the request carries. These log lines hold no IP address. Cloudflare, which hosts the server, adds its standard request details to its logs, keeps them for a few days, and then deletes them.

Cloudflare

Cloudflare runs the network the server and this site are served from, and handles requests as it does for any website. See Cloudflare's privacy policy.
