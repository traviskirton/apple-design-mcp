01 / Setup

How to
use it.

Works in Claude, ChatGPT, Perplexity, Grok, Cursor, VS Code, and pretty much anything else. Pick yours:

Claude

Chat, projects, Claude Design, desktop and mobile apps

  1. 01Open Settings → Connectors and choose Add custom connector.
  2. 02Name it "Apple Design" and paste the URL.
  3. 03Ask for an Apple screen.

Claude Code

Run in your terminal

$ claude mcp add --transport http apple-design https://apple-design-mcp.com/mcp

Cursor

In ~/.cursor/mcp.json

{ "mcpServers": { "apple-design": { "url": "https://apple-design-mcp.com/mcp" } } }

VS Code

In .vscode/mcp.json

{ "servers": { "apple-design": { "type": "http", "url": "https://apple-design-mcp.com/mcp" } } }

ChatGPT

Plus, Pro, Business and Enterprise, on the web

  1. 01Go to chatgpt.com/plugins.
  2. 02Click +, then Add custom MCP server.
  3. 03Name it "Apple Design", paste the URL under Server URL and choose No authentication.
  4. 04Tick I understand and want to continue, then click Create as a plugin.
  5. 05Install Apple Design from your personal plugins.
  6. 06In a new chat, type @ and pick Apple Design.

If + doesn't show Add custom MCP server, turn on Developer mode at chatgpt.com/settings/security and reload the Plugins page.

Perplexity

Pro, Max and Enterprise

  1. 01Open Plugins in the sidebar (or Customize → Connectors).
  2. 02Click Add custom → Connector → Add MCP connector, then select Remote.
  3. 03Name it "Apple Design", paste the URL under MCP Server URL, set Authentication to None and Transport to Streamable HTTP.
  4. 04Tick the risk acknowledgement and click Add.
  5. 05Click the Apple Design card on the Plugins page to enable it.

Grok

grok.com

  1. 01Go to grok.com/connectors.
  2. 02Click New Connector, then select Custom.
  3. 03Name it "Apple Design", paste the URL under Server URL and click Add Connector.
  4. 04Start a new chat. Apple Design's tools are available without a per-chat toggle.

Anything else

Add the URL as a remote MCP server. No authentication.
