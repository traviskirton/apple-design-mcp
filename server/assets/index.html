How to use it

Works in Claude, Cursor, VS Code, and pretty much anything else.

Pick yours. Try: “Design a Settings screen for iPhone 18 Pro, light and dark. Place Apple's components as they are.”

https://apple-design-mcp.com/mcp
claude mcp add --transport http apple-design https://apple-design-mcp.com/mcp
{ "mcpServers": { "apple-design": { "url": "https://apple-design-mcp.com/mcp" } } }
{ "servers": { "apple-design": { "type": "http", "url": "https://apple-design-mcp.com/mcp" } } }

Claude (chat, projects, Claude Design, desktop and mobile apps).
1. Open Settings → Connectors and choose Add custom connector.
2. Name it “Apple Design” and paste the URL.
3. Ask for an Apple screen.

Claude Code. Run this once in a terminal.

Cursor. Add this to ~/.cursor/mcp.json.

VS Code. Add this to .vscode/mcp.json.

ChatGPT (Plus, Pro, Business and Enterprise, on the web).
1. Open Settings → Connectors → Advanced and turn on Developer mode.
2. Back on Connectors, click Create.
3. Name it “Apple Design”, paste the URL and choose No authentication.
4. In a new chat, open the + menu, choose Developer mode and tick Apple Design.
On Business and Enterprise, a workspace owner has to allow developer mode first.

Anything else. Add the URL as a remote MCP server. No authentication.

Proof

Same brief, same model.

Without it, the AI guesses screen sizes, draws its own icons and rebuilds tab bars in CSS. With it, it places Apple's own symbols, components and frames.
