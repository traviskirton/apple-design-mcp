The setup

Add one URL. Then ask for a screen.

There is nothing to install and no account to make. The connector shows up in chat, in projects and in Claude Design.

  1. 1

    Open Connectors.

    On claude.ai, open Settings, then Connectors, and choose Add custom connector.

  2. 2

    Paste the URL.

    Name it Apple Design and paste https://apple-design-mcp.com/mcp. Save. There is no sign-in step.

  3. 3

    Ask for an Apple screen.

    Name the device and the parts. Claude calls the server for sizes, guidelines, symbols and components.

Try one of these.

Ask for Apple's SVGs to be placed as they are. Without that line, models often rebuild components in code and drift from Apple's look.

  • A Settings screen. “Design a Settings screen for iPhone 17 Pro, light and dark. Use Apple Design for the screen size, SF Symbols and Apple's own components.”
  • An iPad notes app. “Design a notes app for iPad Pro 13 with a sidebar, a list and a detail view. Place Apple's UI kit SVGs as they are; only change their icons and labels.”
  • A Mac window. “Design a macOS 27 window for a photo editor with a toolbar and an inspector. Show it inside a MacBook Air frame.”

claude mcp add --transport http apple-design https://apple-design-mcp.com/mcp

Questions? Answers.

  • What does it cost?

    Nothing. There is no account, no key and no plan to choose.

  • Which apps can use it?

    It was built and tested in Claude Design, where it makes the biggest difference. It also works in Claude chat, Claude projects, Claude Code and other apps that accept a remote MCP server over Streamable HTTP with no authentication.

  • How current are the guidelines?

    They were copied from Apple's site on 19 November 2026. Ask Claude to call get_pack_info to see the date the live server holds. The server is refreshed after Apple's major releases.

  • The tools look out of date in my app.

    Remove the connector and add it again. Apps keep the tool list they first saw until the connector is added again.

  • What does the server keep?

    No account and no conversation. Each tool call is logged for a short time to keep the server running. Read the privacy policy

  • Is this made by Apple?

    No. It is an independent project and is not affiliated with or endorsed by Apple.
